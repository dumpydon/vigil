Questions

Before you download.

Is it really free?

Yes. The public beta is free, with no account, subscription, or paid service to set up. Download it, choose a daily goal, and keep your application history on your own Mac.

Why does macOS ask me to approve it?

This beta uses an ad-hoc code signature and is not notarized by Apple. After trying to open the downloaded app, use System Settings → Privacy & Security → Open Anyway if you trust this download. The install guide shows the steps. We do not ask you to disable Gatekeeper.

Is the download verified?

The release process checks the app bundle, signature, architecture, and included assets. Each download has a SHA-512 checksum in the release files so you can compare the file you received. Ad-hoc signing is not Apple notarization.

Do my applications leave my Mac?

The public Mac app stores its counts, history, goals, drafts, and alert inbox locally. It has no account login, telemetry, or cloud synchronization. Choosing a JSON or CSV export writes a file to the destination you choose.

What does it work with?

Apply Vigil requires macOS 13 or later. Choose Apple Silicon for an M-series Mac, or Intel for an Intel processor. It uses macOS’s existing web engine, with a native menu bar, glass panels, and optional system notifications. Apple Silicon has been exercised on macOS 15; physical Intel and clean macOS 13 runtime checks are still pending for this beta.

Does it apply to jobs for me?

You log applications after you submit them. The app does not access your LinkedIn account, read your browser, or send applications automatically. Easy Apply and external/form counts stay separate.

Which permissions does it need?

Notifications are optional and requested when you enable banners. Launch at login is optional too. Application tracking does not require Accessibility, Automation, Screen Recording, camera, or microphone access.

Can I move my history to another Mac?

Yes. Export a JSON backup from Settings and restore it on your other Mac. Entries keep their IDs, identical records are skipped, and existing conflicting values are preserved. CSV export is available for reviewing your records. Personal cloud sync is planned for later.

How do updates and removal work?

Download a new version from this page and replace the app in Applications. Updates are manual in this beta. To remove it, save a JSON backup, quit, disable Launch at login if enabled, then move the app to Trash. Local history is retained separately unless you remove it yourself.
