Install Apply Vigil

A quiet watch,
in a few simple steps.

Download the beta, move it into Applications, and approve the first open when macOS asks. Your own application history starts empty.

Watch the first launch

15 seconds. Pause or choose a step whenever you need.

For the unverified-developer warning, choose Done (or Cancel / OK) instead of Move to Bin/Trash if you intend to continue. Only approve a download you trust. A “damaged” or “will damage your computer” warning needs investigation; contact us.

Try opening Apply Vigil

Open it from Applications. If macOS shows an unverified-developer or unverified-app warning, choose Done (or Cancel / OK) to dismiss it. Keep the app in Applications instead of choosing Move to Bin/Trash.

This beta has an ad-hoc signature and has not been notarized by Apple. Continue only if you trust this download.

4

Approve the first launch

Open System Settings → Privacy & Security, scroll to Security, and find Apply Vigil’s blocked-app notice. Choose Open Anyway, then confirm Open. Authenticate with Touch ID or your Mac login password if requested.

On some macOS versions, choose Open before Open Anyway. If the notice is missing, try opening the app again; the button is available for about an hour. Keep Gatekeeper enabled.

Your data stays with you.

The public app uses local storage and a separate identity from the owner's cloud-connected build.

Local records
Application history, goals, drafts, and the alert inbox stay in the app’s system-managed WebKit storage on this Mac.
Backups
Use Settings → JSON backup before replacing or removing data. Restore that file on another Mac to move your history. CSV is available for reviewing entry records.
First-launch checks
This release has an ad-hoc signature, not an Apple Developer ID or notarization ticket. Compare its SHA-512 value with the published release files if you wish to verify the downloaded file.

Updates, at your pace.

Updates are manual in this beta. Download the new version from the download page and replace the app in Applications. Keep a backup of your history.
