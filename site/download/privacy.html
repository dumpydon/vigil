Privacy

Your history stays yours.

The public Apply Vigil Mac app is local-first and needs no account.

Application data

Your counts, UTC dates, goals, drafts, and alert inbox are stored in the app’s system-managed local WebKit data on your Mac. The public binary does not connect to the existing owner’s Cloudflare workspace and blocks the owner-account API bridge.

No monitoring or telemetry

The app does not read your browser, LinkedIn account, screen, prompts, or other applications. It does not upload application history or include an analytics SDK. Counts are entered manually.

Files you choose

JSON and CSV exports are written using a save dialog to the location you choose. JSON restore reads the file you select and merges missing records locally. Keep backups somewhere you control.

Login and Keychain

The public app requires no account and does not read or write saved owner-session Keychain items. Beta 2 removes the legacy Keychain integration. macOS first-launch approval is a separate system check and can still require authentication.

Optional Mac features

macOS notifications and launch at login are optional. The app requests notification permission when you enable banners. It does not require Accessibility, Automation, Screen Recording, camera, or microphone permission.

This website and downloads

The website is hosted on Cloudflare and release files are hosted on GitHub. Those services receive ordinary web requests when you visit or download. This site has no added analytics scripts, advertising pixels, or account forms. Product demonstrations use synthetic data.

Moving or removing data

Export a JSON backup before removing the app or its local data. Moving the app to Trash does not automatically erase its history or preferences. Cloud sync is not included in this public beta.
